## Українською

Сервіс для команди MWR Life: за хвилину створює вітальну картку для нового партнера або з нагоди нового статусу — у фірмовому стилі, з правильним шрифтом і розміщенням.

### Як користуватися

1. **Оберіть шаблон** — новий партнер (New Lifestyle Ambassador), бонус швидкого старту, статус або бонус.
2. **Впишіть ім'я та прізвище** в окремі поля: спочатку ім'я, потім прізвище. Бажано латиницею — як у закордонному паспорті та в кабінеті MWR Life.
3. **Додайте фото** — натисніть на коло або кнопку «Фото».
4. **Налаштуйте фото:** пересувайте пальцем або мишкою, масштаб — двома пальцями, коліщатком миші або повзунком. Є кнопки «Повернути», «Дзеркало» та «Скинути».
5. **Завантажте картку** (JPG — менший файл, PNG — максимальна якість) або натисніть «Поділитися», щоб одразу надіслати в Telegram.

### Корисно знати

- Підпис робиться автоматично: шрифт Montserrat Bold, великі літери, по центру. Довгі імена сервіс сам зменшує або переносить на другий рядок.
- Розмір готової картки — 2000×2000 пікселів.
- Найкраще підходить чітке фото, де обличчя добре видно, без інших людей поруч.
- **Фото нікуди не завантажується** — картка збирається прямо у вашому браузері.
- Мову інтерфейсу (UA / RU) можна перемкнути вгорі праворуч.

### Для адміністратора

- `index.html` — сторінка і вся логіка.
- `assets/t/` — шаблони (WebP 2000×2000 з прозорим колом під фото).
- `assets/fonts/` — шрифт Montserrat Bold.
- Порядок статусів, місце та колір підпису для кожного шаблону задаються в `index.html` (список шаблонів, параметри `box` і `color`).
- Оновити сайт: **Add file → Upload files** → перетягнути змінені файли → **Commit changes**. Зміни з'являться за 1–2 хвилини.

## По-русски

Сервис для команды MWR Life: за минуту делает поздравительную карточку для нового партнёра или по случаю нового статуса — в фирменном стиле, с правильным шрифтом и расположением.

### Как пользоваться

1. **Выберите шаблон** — новый партнёр (New Lifestyle Ambassador), бонус быстрого старта, статус или бонус.
2. **Впишите имя и фамилию** в отдельные поля: сначала имя, потом фамилию. Желательно латиницей — как в загранпаспорте и в кабинете MWR Life.
3. **Добавьте фото** — нажмите на круг или кнопку «Фото».
4. **Настройте фото:** двигайте пальцем или мышкой, масштаб — двумя пальцами, колёсиком мыши или ползунком. Есть кнопки «Повернуть», «Зеркало» и «Сбросить».
5. **Скачайте карточку** (JPG — меньше файл, PNG — максимальное качество) или нажмите «Поделиться», чтобы сразу отправить в Telegram.

### Полезно знать

- Подпись делается автоматически: шрифт Montserrat Bold, заглавные буквы, по центру. Длинные имена сервис сам уменьшает или переносит на вторую строку.
- Размер готовой карточки — 2000×2000 пикселей.
- Лучше всего подходит чёткое фото, где хорошо видно лицо, без других людей рядом.
- **Фото никуда не загружается** — карточка собирается прямо в вашем браузере.
- Язык интерфейса (UA / RU) переключается вверху справа.

### Для администратора

- `index.html` — страница и вся логика.
- `assets/t/` — шаблоны (WebP 2000×2000 с прозрачным кругом под фото).
- `assets/fonts/` — шрифт Montserrat Bold.
- Порядок статусов, место и цвет подписи для каждого шаблона задаются в `index.html` (список шаблонов, параметры `box` и `color`).
- Обновить сайт: **Add file → Upload files** → перетащить изменённые файлы → **Commit changes**. Изменения появятся через 1–2 минуты.
